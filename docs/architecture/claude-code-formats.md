# Formatos de configuración de Claude Code usados por la fábrica

> Verificado contra https://code.claude.com/docs/en/ (hooks, sub-agents, skills, mcp, permissions): 2026-11-06 en general; skills y subagentes re-verificados el 2026-11-08. Revisar en cada `skill-review`.

- **Hooks** (`.claude/settings.json`): `hooks.<Evento>[] = { matcher, hooks: [{ type: "command", command }] }`. Eventos usados: `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `SubagentStop`, `Stop`, `PreCompact`, `SessionEnd` (la documentación de 2026-11-09 lista además `PermissionRequest`, `PermissionDenied`, `PostToolUseFailure`, `SubagentStart`, `Notification`, `InstructionsLoaded`, `ConfigChange`, `TaskCreated`, `TaskCompleted`, `FileChanged`, `WorktreeCreate` y otros, que la fábrica no usa). Entrada por stdin en JSON (`tool_name`, `tool_input`, `cwd`, `hook_event_name`…). Bloqueo: **exit code 2** con el motivo en stderr (o JSON `hookSpecificOutput.permissionDecision`). Ruta del proyecto: `${CLAUDE_PROJECT_DIR}`.
- **Subagentes** (`.claude/agents/**/*.md`): se escanean recursivamente, pero **las subcarpetas no afectan a la identidad**: el nombre sale solo del campo `name` (el prefijo con ámbito solo existe en subagentes de plugins). Por eso los `name` de la fábrica son únicos entre carpetas. Obligatorios `name` y `description`; opcionales `tools`, `disallowedTools`, `model`, `permissionMode`, `maxTurns`, `skills`, `mcpServers`, `hooks`, `memory`, `isolation`, `effort`…
- **Skills**: `.claude/skills/<nombre>/SKILL.md`; **un skill dentro de una subcarpeta (`.claude/skills/grupo/nombre/`) no se descubre**, de ahí la estructura plana (ADR-0028). Todos los campos son opcionales; la plataforma trunca `description` + `when_to_use` a 1.536 caracteres en el listado, y la fábrica se impone un máximo de 200 por su cuenta. `metadata` es un mapa libre: ahí van el bloque (01–31) y el nivel T1/T2/T3.
- **Comandos**: `.claude/commands/<nombre>.md` sigue funcionando, pero los comandos se han unificado con los skills (un comando `deploy.md` y un skill `deploy/SKILL.md` crean el mismo `/deploy`). Las subcarpetas de `commands/` sí se admiten y dan nombres con dos puntos (`commands/frontend/component.md` → `/frontend:component`), así que los de la fábrica se invocan como `/00-intake:project-discover`.
- **Hooks por evento:** `UserPromptSubmit` recibe `prompt` y bloquea con JSON `{"decision":"block","reason":…}`; `SubagentStop` recibe `agent_type`, `last_assistant_message` y `stop_hook_active` y usa el mismo control que `Stop`; el stdout de `PreCompact` se usa como instrucciones para el resumen (máximo 10.000 caracteres); `SessionEnd` recibe `reason` y no puede bloquear. Verificado el 2026-11-09.
- **`.mcp.json`**: `{ "mcpServers": { "<n>": { "type": "stdio|http|sse", ... } } }`.
- **Permisos**: `permissions.allow|ask|deny` con reglas `Tool(patrón)`.
