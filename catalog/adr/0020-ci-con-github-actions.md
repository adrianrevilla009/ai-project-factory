# ADR-0020: CI con GitHub Actions

- **Estado:** aceptado
- **Fecha:** 2026-11-06

## Contexto
Decisión D20 del brief de la fábrica (`docs/FACTORY_BRIEF.md` §3).

## Decisión
Workflows reutilizables, OIDC, acciones fijadas por SHA.

## Por qué
Integración con el repositorio y soporte de OIDC sin secretos de larga vida.

## Consecuencias
GitLab CI y Jenkins quedan como T3.
