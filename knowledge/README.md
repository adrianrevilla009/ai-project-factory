# knowledge

Memoria que acumula la fábrica entre proyectos. Hoy está **vacía** a propósito: se rellena al cerrar proyectos reales.

El comando `lessons-capture` (fase `06-close`) escribe aquí, siempre como propuesta que una persona revisa:
- `lessons-learned/` — cambios sugeridos a skills o hooks.
- `domain-profile-seeds/` — perfiles de dominio reutilizables, solo con permiso del cliente y sin datos sensibles.

Las subcarpetas se crean la primera vez que se escribe en ellas. `enforce_gate_approval` permite editar `knowledge/` en cualquier fase.
